# Datheon – Full Stack Web Development Internship

A collection of three web development projects completed as part of the Datheon Full Stack Web Development Internship. This repository demonstrates practical experience in frontend development, interactive web applications, responsive UI design, and backend development using modern web technologies.

## 📌 Projects Overview

### Task 1: Personal Developer Portfolio

A personal portfolio website designed to showcase professional information, technical skills, projects, education, certifications, and resume details.

**Technologies Used**
- React.js
- TypeScript
- HTML5
- CSS3
- Vite

**Key Features**
- Personal introduction and profile
- Technical skills and education sections
- Project showcase with interactive components
- Certifications and experience sections
- Resume viewing and download functionality
- Responsive user interface

**Project Location:** `Task-1/Personal-Developer-Portfolio/`

### Task 2: Dynamic Task Manager and Productivity Tracker

A web-based task management application designed to help users organize tasks and manage daily activities through an interactive interface.

**Technologies Used**
- HTML5
- CSS3
- JavaScript

**Key Features**
- Interactive task management interface
- Dynamic user interactions
- Task organization and productivity-focused design
- Responsive layout

**Project Location:** `Task-2/Dynamic-Task-Manager-and-Productivity-Tracker/`

### Task 3: Real-Time Weather Forecast

A weather application that uses a backend server and web technologies to present weather-related information through a user-friendly dashboard.

**Technologies Used**
- Node.js
- Express.js
- JavaScript
- EJS
- HTML5
- CSS3

**Key Features**
- Server-side application using Express.js
- Dynamic dashboard rendered with EJS
- Organized frontend assets
- Weather-focused user interface
- Backend integration for weather data

**Project Location:** `Task-3/Real-Time-Weather-Forecast/`

## 🚀 Getting Started

### Prerequisites

Install the following tools before running the projects that require them:

- [Node.js and npm](https://nodejs.org/)
- [Git](https://git-scm.com/)
- A modern web browser

### Task 1: Run the Portfolio

Open a terminal and navigate to the portfolio application directory:

```bash
cd Task-1/Personal-Developer-Portfolio/somya-developer-portfolio-main
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Task 2: Run the Task Manager

Navigate to:

```text
Task-2/Dynamic-Task-Manager-and-Productivity-Tracker/
```

Open `index.html` in your web browser to run the application.

### Task 3: Run the Weather Forecast Application

Navigate to the backend application directory:

```bash
cd Task-3/Real-Time-Weather-Forecast
```

Install dependencies:

```bash
npm install
```

Configure the environment variables required by the application in a local `.env` file, following the variable names expected by the application code. Keep API keys and other secrets private.

Start the application using the start script defined in `package.json`. For example, if the project defines a `start` script:

```bash
npm start
```

Open the local address and port displayed by the application.

**Note:** The weather application requires the appropriate weather API configuration to retrieve live data.

## 🔐 Security

- Environment files containing secrets are excluded from version control.
- API keys and credentials should never be committed to a public repository.
- Use environment variables to manage sensitive configuration.
- Keep `.env.example` files limited to placeholder values.
