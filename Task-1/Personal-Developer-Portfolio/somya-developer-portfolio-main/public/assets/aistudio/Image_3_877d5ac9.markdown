## Brand & Style

This design system expresses the craft, technical precision, and modern architectural vision of an ambitious Computer Science student and software engineer. The aesthetic blends modern minimalism with technical polish—pairing the disciplined, calm depth of dark-first developer tools with the vibrant, luminous energy of high-tier product engineering.

### Brand Personality
- **Rigorous & Intentional:** Every element, margin, and typography scale conveys deliberate choice and structural mastery.
- **Architectural & Modern:** Deep slate backdrops paired with crisp semi-transparent borders reflect the clarity of modular software architecture.
- **Dynamic & Luminous:** Electric cyan and radiant indigo-violet accents highlight critical milestones, live demos, and technical badges without distracting clutter.
- **Recruiter-Ready & Approachable:** Clear hierarchy, rapid scanning affordances, and unmistakable CTAs that honor the recruiter’s time while leaving an indelible impression of seniority.

### Design Movement & Influence
The visual system fuses **Modern Developer Minimalism** with **Glass-Layered Depth**. It borrows the clean utility of leading devtool interfaces (subtle 1px borders, precision badges, monospaced metadata) while incorporating atmospheric ambient glows and soft rounded surfaces to maintain an inviting, human touch.

## Typography

The typography pairings strike an intentional dialogue between human clarity and technical precision.

### Type Roles
- **Primary Typeface (`Inter`):** Drives headlines, descriptive copy, navigation, and overarching layout structures. It delivers exceptional legibility on digital screens, tight letter-tracking for punchy titles, and neutral, confident body rendering.
- **Technical Monospace (`JetBrains Mono`):** Applied systematically to all computational artifacts: technology tags, code snippets, git metrics, deployment logs, timestamps, and architectural labels.

### Hierarchy & Responsive Rules
- Hero typography transitions from `display-hero` (`3.75rem`) on desktop down to `display-hero-mobile` (`2.25rem`) below 768px viewports to eliminate horizontal overflow.
- Maintain a minimum of `1.55` line-height for project case studies and body passages to prevent reader fatigue.
- Monospace tokens use `label-code` and `label-code-sm` with slightly reduced vertical line height to ensure tags remain compact and vertically centered inside pill badges.

## Layout & Spacing

The layout system is founded on an 8pt structural rhythm, bound by a maximum width container to ensure optimal scanning on wide-aspect displays.

### Layout Model
- **Grid Architecture:** 12-column fluid grid system on desktop (`min-width: 1024px`) with a `1.5rem` (`24px`) gutter.
- **Tablet Reflow:** 6-column fluid grid (`min-width: 640px` to `1023px`) with a `1.25rem` (`20px`) gutter.
- **Mobile Reflow:** Single-column stacked layout (`max-width: 639px`) with `1rem` (`16px`) gutters and margins.
- **Max Width Container:** Content is constrained to `72rem` (`1152px`) centered with automatic horizontal margins (`margin-desktop-max`), ensuring recruiters on ultra-wide screens do not encounter overextended line lengths.

### Sectional Spacing
- Major sections (Hero, Featured Projects, Experience & Education, Skills Grid, Contact) are separated by `space-3xl` (`6rem`) on desktop and `space-2xl` (`4rem`) on mobile.
- Interior card spacing uses `space-lg` (`1.5rem`) for generous breathing room around complex project descriptions and screenshots.

## Elevation & Depth

Visual depth is achieved through layered tonal planes, subtle dark-slate glows, and frosted boundary borders rather than standard drop shadows.

### Surface Tiers
- **Layer 0 (Canvas):** `#0B1120` solid canvas background.
- **Layer 1 (Resting Cards):** `#0F172A` with a 1px solid border of `#1E293B`.
- **Layer 2 (Elevated & Hovered Surfaces):** `#1E293B` background, with a 1px border highlighted to `#334155`.
- **Layer 3 (Overlays, Dropdowns & Modals):** Semi-transparent `rgba(15, 23, 42, 0.85)` paired with a `backdrop-filter: blur(16px)` and a subtle ambient outer shadow.

### Ambient Accent Glows
Interactive hover states on primary cards and featured project tiles emit a soft, diffused radial highlight:
- **Card Hover Glow:** `box-shadow: 0 10px 30px -10px rgba(99, 102, 241, 0.15), 0 0 1px 1px rgba(99, 102, 241, 0.3);`
- **Cyan Secondary Glow:** `box-shadow: 0 8px 24px -8px rgba(56, 189, 248, 0.2);`
- In Light Mode, surfaces rely on `box-shadow: 0 1px 3px 0 rgba(0, 0, 0, 0.05), 0 10px 15px -3px rgba(15, 23, 42, 0.05);` with crisp `#E2E8F0` hairline borders.

## Shapes

The system relies on a consistent `0.5rem` (`8px`) base radius (`roundedness: 2`), balancing software engineering rigor with modern ergonomics.

### Corner Radius System
- **Base Components (`rounded` / 0.5rem):** Standard buttons, text input fields, code blocks, and dropdown menus.
- **Containers & Project Cards (`rounded-lg` / 1rem):** Portfolio project cards, experience timeline panels, and modal containers.
- **Hero & Modal Outer Frames (`rounded-xl` / 1.5rem):** Hero highlight containers and featured showcase media wrappers.
- **Pills & Status Indicators (`rounded-full`):** Technology tags, live status indicators (e.g., "Available for internships"), and avatar images.

## Components

### Buttons
- **Primary Button:** Gradient surface `linear-gradient(135deg, #6366F1, #8B5CF6)` with white bold text (`label-ui`), `0.5rem` border-radius, and horizontal padding `space-lg`, vertical padding `space-sm`. On hover, scale to `1.02` with an ambient glow (`rgba(99, 102, 241, 0.4)`).
- **Secondary / Ghost Button:** Transparent background, `1px` border of `#334155`, text color `#F8FAFC`. On hover, surface shifts to `#1E293B` and border shifts to `#6366F1`.
- **Icon Button:** 40x40px square, `0.5rem` radius, centered SVG icon with `#94A3B8` fill, shifting to `#38BDF8` on hover.

### Technology Chips & Badges
- **Code Tech Pill:** Background `rgba(99, 102, 241, 0.08)`, border `1px solid rgba(99, 102, 241, 0.2)`, text `#38BDF8` styled in `label-code-sm`. Padding: `0.25rem 0.625rem`. Rounded full pill.
- **Status Badge:** A 6px pulsing green dot (`#10B981`) followed by text "Open to Summer 2025 Roles" in `label-code-sm` over a dark slate chip.

### Project Cards
- **Base Styling:** Background `#0F172A`, 1px border `#1E293B`, rounded-lg (`1rem`), inner padding `space-lg`.
- **Card Header:** Project title in `headline-md`, live demo link, and GitHub repository icon.
- **Card Media:** Aspect ratio 16:9 frame with `0.5rem` inner radius, featuring subtle bottom border separating it from body content.
- **Interaction:** Smooth `transform: translateY(-4px)` with indigo glow on focus/hover.

### Lists & Timeline (Experience / Education)
- Vertical hairline rule in `#1E293B`.
- Node bullets styled as concentric glowing circles (outer ring `#334155`, center dot `#38BDF8`).
- Timeline items contain role title (`headline-sm`), organization name (`body-md`), duration badge (`label-code`), and bulleted impact metrics in `body-sm`.

### Input Fields & Contact Elements
- Background `#0B1120`, border `1px solid #334155`, text `#F8FAFC`, placeholder `#64748B`.
- Focus state: Border transitions to `#6366F1` with an outer ring `0 0 0 2px rgba(99, 102, 241, 0.2)`.
- Roundedness `0.5rem`, padding `space-md`.

### Code Snippets & Architecture Callouts
- Monospace block using JetBrains Mono with syntax color-coding: Keywords (`#8B5CF6`), Strings (`#38BDF8`), Variables (`#F8FAFC`), Comments (`#64748B`).
- Clean copy-to-clipboard button placed at top-right corner.
