Book A Doctor • Architecture Spec

System Overview

Developed as a comprehensive appointment orchestrator for healthcare providers. The system replaces phone or in-person queues with verified digital scheduling and role separation.

Key Engineering Features

  • Three-Tiered Role Access: Separate portals and privileges for Patients (booking/history), Doctors (availability/schedules), and Admins (system moderation).
  • 4 MongoDB Schemas: Structured collections for User, Doctor Profile, Appointment, and Department Records with Mongoose relational population.
  • MVC Clean Architecture: Clear separation between Models (schemas), Controllers (business logic), and Express route endpoints.
  • Authentication & Security: JSON Web Tokens (JWT) for stateless session handling combined with bcrypt password hashing.

Technology Stack

React.js Node.js Express.js MongoDB Mongoose ODM JWT Auth

Sports Scheduler • Architecture Spec

System Overview

Designed to solve scheduling gridlocks and tournament roster friction in collegiate and community sports leagues, pairing lightweight Express controllers with cloud document persistence.

  • Firebase Firestore Integration: Low-latency document store enabling real-time match fixture updates and roster management.
